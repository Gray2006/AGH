# AGH 证明了什么，没证明什么

这份文档是对项目的自我审计。每个结论后面都跟着证据的强度，不掩饰。

## 证明了（有对照、有数字、可复现）

### 治理层不是装饰

三组「有治理 vs 无治理」对照，同一批输入，对照组只把治理换成朴素实现：

| 场景 | 有治理 | 无治理 |
|---|---|---|
| 伪造出处（改载荷 / 改签名 / 未知签发者 / 重放） | 80/80 拦截 | 0/80 |
| 超预算调用 | 10/10 拒绝 | 0/10 |
| 篡改日志一行 | 20/20 检出 | 0/20 |

合法输入误拒 0。跑一次几秒，进 CI。

**这条的意义**：把「可审计」从口号变成了可测的实验——拿掉治理层，看坏行为会不会进来。这个方法论可以套到任何声称「可信」的系统上。

### 结论可复现

- 仲裁是纯函数（固定种子）
- 日志是哈希链（改一行就断）
- M0 管线与 LLM 变异路径都支持 L1 逐位重放：同样的输入重跑，曲线逐位一致

### 执行型验证器能工作

- 期望值只留父进程，子进程只回传输出——候选无法伪造「通过」
- visible / hidden 分离有效：参考解 hidden 全 1.0，每个已知 bug 变体都被杀死
- 12 道题、每道带参考解与突变体，突变测试是给测试本身做的质量检查

## 没证明（做了，但测不出收益）

### 进化/搜索在现有任务族上没有收益

| 尝试 | 结果 |
|---|---|
| 规则变异 vs 随机搜索 | 同分 |
| LLM 变异 vs 规则变异 | 同分 |
| 换更强模型（flash → pro） | 差 ≤0.006，噪声内 |
| 扩大策略空间（135 → 270） | 真模型仍触顶 |
| 学习进步奖励（LP） | 比绝对分数差 |
| 分级目标（ladder） | 与单一分数完全相同 |
| 蜂巢协作（分片合并） | 0.5534 ≤ 单体 0.5563 |

**根因**：没有真模型会做错的题。五类难度尝试（纯函数、边界密集、单 bug、多 bug 模块、更大空间）全部失败——`deepseek-v4.1-flash` 对 20 道题全对。

离线模拟模型上的「显著提升」来自 `p_correct=0.4` 的人为空间，**不可外推**。

### 动机理论没有落地验证

`docs/motivation.md` 映射了 SDT / SRL / 目标设定 / 实施意图 / 计算内在动机五个理论到 AGH 机制。落地了两项（LP、分级目标），两项都没测出收益。

剩下两项（if-then 策略、自主选择）需要新任务族，没做。

### 不是产品

- 没有真实用户
- 没有生产部署
- 没有接入实际业务的适配层

## 可复用的积木

这些模块可以单独拿走，不依赖进化部分：

| 模块 | 作用 |
|---|---|
| `crypto.ProvenanceGateway` + `EnvelopeVerifier` | 签名、验签、防重放 |
| `gate.WriteGate` | 验签 → 风险 → 隔离 |
| `ledger.Ledger` | 预授权、结算、超额拒绝 |
| `eventlog.EventLog` | 哈希链日志，L1 重放 |
| `anchoring` | 锚定到本地/JSONL/git tag |
| `execverify.ExecutionVerifier` | 子进程执行验证，visible/hidden 分离 |
| `audit.AuditSession` | 三行接入的审计 SDK |
| `ui.render_html` | 自包含 HTML 报告 |

## 负面结果清单（省别人时间）

1. 自定规则上的进化搜索：种子在顶点，任何变异只减分
2. 换更强模型：差 ≤0.006，噪声内
3. 蜂巢协作：分片合并 ≤ 单体
4. 策略空间扩大：真模型仍触顶
5. LP 奖励：比绝对分数差
6. 分级目标：与单一分数相同
7. 五类难度尝试：全部全对
8. 搜索旋钮（tournament / elite_only）：分数完全不变

## 一句话

**AGH 的价值不在「它能自我进化」，而在「它把多智能体治理做成了可测的东西，并且诚实记录了哪些假设是错的」。**

要当产品用，砍掉进化那半，把审计那半包成三行 SDK——现在已经是了（`AuditSession`）。
要当研究用，负面结果清单能省几周时间。
